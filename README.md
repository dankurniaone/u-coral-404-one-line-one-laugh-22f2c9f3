Entry for the [One Line, One Laugh](https://make.fun/competitions/u-coral-404-one-line-one-laugh-22f2c9f3) bounty on make.fun.

One funny line, at most 200 characters. A judge model reads entries two at a time and the funnier line wins.

## The line

> My printer only jams when the document matters. It smells deadlines the way sharks smell blood, except sharks don't charge per page.

## How it works

`main.py` (stdlib only) writes the line to `/output/entry.txt` and self-checks the gate: UTF-8 text, 1 to 200 characters, not only whitespace.

Run it:

```
python3 main.py
```
